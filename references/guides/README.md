# references/guides/ — статьи и гайды по написанию резюме

Здесь лежат **общие материалы о том, как писать резюме**: ссылки на статьи и
сохранённые копии (PDF/Markdown). Примеры чужих резюме — в
[`real_resumes/`](../real_resumes/).

## Скачанные материалы

Сохранены 2026-10-08. Начать с **Orosz → JoinAI → MIT Broad**; затем выбрать
материалы по ML или академическому CV. Время чтения приблизительное.

PDF Orosz скачан без изменений с [сайта автора](https://thetechresume.com/A_Good_Tech_Resume.pdf).
Тексты Chip Huyen взяты из авторского репозитория; иллюстрация — в `images/`.
Остальные статьи сохранены как текстовые копии в Markdown, без пересказа.
У каждого текста указаны автор, исходный URL и способ сохранения. Копии JoinAI
и MIT Broad получены через веб-просмотр, поэтому исходная вёрстка и часть
внешних ссылок не сохранены. Внешние страницы по ссылкам не скачивались.

[Пример резюме MIT Broad с комментариями (PDF, 3 страницы)](https://mitcommlab.mit.edu/broad/wp-content/uploads/sites/5/2016/09/Broad_CommKit_CV_Resume_eg_resume.pdf)
доступен по ссылке; локальной копии нет — сервер вернул HTTP 403 при скачивании.

Материалы отражают рекомендации их авторов, а не обязательные правила.
У Orosz пособие 2020 года; советы о системах отбора стоит оценивать с учётом
даты. В статье Хабра количество строк кода не стоит брать за основной
показатель результата.

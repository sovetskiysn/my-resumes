# Решения репозитория

Здесь лежат решения с неочевидной ценой: что выбрали, что отвергли и с какими
недостатками согласились. Каждое выглядит как недосмотр для того, кто не знает
истории, — поэтому его тянет «починить». Запись появляется, когда решение принято и у
него есть цена, из-за которой его захотят отменить. Действующее правило живёт в
[AGENTS.md](../AGENTS.md); сюда попадает обоснование.

Это не рабочий блокнот и не список задач. При пересмотре решения прежнюю запись не
удаляют: отмечают, каким решением и почему она заменена. Пути ниже указаны
относительно корня репозитория.

## `AGENTS.md` строчными буквами и без `CLAUDE.md`

Контекст агентов лежал в `AGENTS.MD`. В сессии Claude Code 2.1.283 от 2026-11-03 этот
файл в контекст не попал — загрузился только глобальный `~/.claude/CLAUDE.md`. Claude
Code и Codex ищут файл по точному имени `AGENTS.md`, а в Linux имена чувствительны к
регистру. Файл переименован в `AGENTS.md`.

Отдельный `CLAUDE.md` не заводим: Claude Code читает `AGENTS.md` сам, а копия под
именем конкретного клиента разъезжается с оригиналом. Так же устроен
`samruk-agents-platform`, откуда перенесена эта схема.

## Образ TeX Live закреплён на `TL2025-historic`

`historic`-теги не двигаются, поэтому сборка воспроизводима и не ломается от
обновлений TeX Live. `latest` отвергнут: он меняется под ногами, и вёрстка, которая
собиралась вчера, может сломаться или сдвинуться без единой правки в исходнике.

**Цена:** новые версии пакетов не приходят сами — обновление образа делается
отдельной осознанной правкой с пересборкой всех версий.

## Версии резюме — независимые копии

Каждая папка `resumes/<версия>/` — самостоятельный LaTeX-проект без общих подключаемых
файлов. Отвергнут вариант с общим `\input` для контактов и образования: он связывает
версии, и обрезка одной ломает соседние.

**Цена:** общий факт (телефон, место работы, опечатка) правится в каждой папке руками;
перед правкой ищем его по всем версиям через `grep -rn ... resumes/`.

## `.build/` не чистится автоматически

Артефакты сборки уходят в `%DIR%/.build`. Набор файлов там фиксированный и
перезаписывается на месте, а `.fdb_latexmk` — кеш latexmk, на котором держатся быстрые
пересборки. Автоочистка эти пересборки бы замедлила.

**Цена:** каталоги остаются на диске; удаляются руками — `rm -rf resumes/*/.build`.

## Латинские имена в `diplomas/`, выданные — в `certificates/`

Кириллица и пробелы в путях ломают ссылки из LaTeX и часть тулинга, поэтому дипломы
переименованы латиницей через `_`. Сертификаты лежат под выданными именами: это файлы
«как выдали», и в имени часто стоит номер сертификата.

**Цена:** два каталога с документами следуют разным правилам именования.
